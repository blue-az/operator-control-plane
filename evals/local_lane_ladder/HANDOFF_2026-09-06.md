## Locked method

- Pin: runner **e9pin** `num_ctx 16384` / `temperature 0.8`. Probe: contract-v1,
  `num_predict` 128, `temperature` 0. `think` off.
- Wall clock: n=3 **warm** (discard load). Report per-task **range**, not a
  grand mean across tasks.
- `OPERATOR_MACHINE=desktop` or `testbench`. New fixture dirs after the GPU
  change; do not append to `testbench-2080-*`.
- Record PCIe gen×width next to every decode row. This board’s GPU0 flipped
  **gen1×16 → gen3×16** in one day.

## Correction 2026-09-06 — the 11–12 s wall clock is from the other arm

**Do not compare the bench to 11–12 s for `gemma4:26b` on `constant-and-callers`.
Use 15–16 s.**

This document correctly flags (line 74) that `225` vs `211` decode is host ollama
**0.32.12** against docker **0.32.15**. But the snapshot then pairs **decode from
the host arm** with **wall clock from the docker arm**. Those are different
configurations and cannot be quoted together.

Measured on the host path (`pi` → `:11434`, ollama 0.32.12,
`gemma4-26b-e9pin-ctx16384-t0p8`), warm trials only, two independent runs:

| run | warm trials | mean |
|---|---|---:|
| `preswap-wallclock-2026-09-05` | 14.9 / 15.0 / 15.1 | **15.0 s** |
| re-check, same box, later | 15.5 / 15.8 / 16.0 | **15.8 s** |

**Reproducible at 15–16 s.** Cold trial 1 is unstable across the two runs (15.8 s
vs 28.9 s) and must not be averaged in.

The `:11435` docker daemon that produced 11–12 s is no longer running, so that
arm is not currently reproducible. **The testbench runs ollama 0.32.12**, matching
the host arm — so the like-for-like comparison is against 15–16 s. Quoting 11–12 s
would make an unchanged bench look ~25% slower and get charged to the i3.

**Reference pair for `gemma4:26b`, both from the 0.32.12 host path:**

| metric | value | source |
|---|---|---|
| decode | **226 tok/s** (224.4–229.0) | `preswap-baseline-2026-09-05` |
| constant-and-callers, warm | **15–16 s** | `preswap-wallclock-2026-09-05` |
| csv-summarize-repair, warm | **46.0 s** (37.7–60.5) | same |

The document's core argument is unaffected and stands: **3090 + i9 is the
combination that cannot be bought back**, post-swap decode may match while
agentic wall clock will carry the i3, and `133` must not be cited. Only the
wall-clock figure needed the arm corrected.

**Version discipline going forward:** record the ollama version alongside every
wall-clock number. A 0.32.12/0.32.15 difference moves this metric ~25% — larger
than the CPU change the swap is meant to measure.
